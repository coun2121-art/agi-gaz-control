# AGI — заявки на поверку газовых счётчиков

MVP веб-приложения для руководителя и работников.

## Возможности
- Роли: руководитель / работник
- Руководитель создаёт заявки
- Все работники видят общую очередь заявок
- Работник может взять заявку в работу и завершить её
- Фото и результат выполнения предусмотрены в модели данных

## Запуск
Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite.
